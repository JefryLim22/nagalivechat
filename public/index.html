FAQ

Pertanyaan yang sering diajukan

Apakah widget memperlambat website saya?

Tidak. Loader hanya berukuran beberapa kilobyte dan dimuat secara asinkron setelah halaman Anda selesai dirender. Antarmuka chat sendiri berjalan di dalam iframe terpisah sehingga tidak ikut memblokir proses render halaman utama.

Apakah CSS website saya bisa bentrok dengan widget?

Tidak bisa. Seluruh antarmuka chat dirender di dalam iframe dengan dokumen sendiri, jadi style website Anda tidak akan memengaruhi widget, begitu juga sebaliknya.

Saya tidak punya website. Masih bisa pakai?

Bisa. Setiap project otomatis mendapat direct chat link seperti /chat/NAGA-XXXX-XXXX-XXXX. Bagikan link tersebut di bio Instagram, QR code di toko fisik, atau tanda tangan email — pelanggan langsung masuk ke ruang chat Anda.

Apa yang terjadi jika semua agent sedang offline?

Widget otomatis beralih ke mode offline dan menampilkan formulir pesan. Pesan tersebut tersimpan di workspace dan bisa dibalas tim Anda lewat email saat kembali online.

Berapa banyak agent yang bisa membalas bersamaan?

Tidak dibatasi secara teknis. Setiap agent punya akun sendiri, bisa mengambil alih percakapan, mengalihkan ke rekan lain, dan menulis catatan internal yang tidak terlihat pengunjung.

Apakah data percakapan aman?

Sesi pengunjung diamankan dengan token bertanda tangan yang hanya memberi akses ke percakapannya sendiri. Sesi agent memakai cookie httpOnly, dan seluruh endpoint publik dilindungi rate limiting.
